# Compare

Compares 2 SVGs via pixels to ensure the cleaning and fixing didn't cause any issues.

## Usage
You can run it by using cargo run.
-- passes args to svgcompare

``` bash
cargo run -- <directory>
```

## Build
You can build using;

``` bash
cargo build
```

## Test
You can test using;

``` bash
cargo test
```

## Install system-wide
You can then install it (optional) using;

``` bash
cargo install --path .
```
